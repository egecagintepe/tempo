# Security & Privacy Policy

## 1. Zero Cloud / 100% Offline
TEMPO does not transmit any user data over the network. All sessions, categories, tasks, and configurations remain strictly on the local device inside SQLite.

## 2. Dual Distribution Architecture
- **Public Open Source:** All files committed to version control must be free of personal identifiers, personal schedules, or sensitive company/university markers.
- **Personal Edition:** Custom configuration lives strictly in untracked files (`.local/personal_profile.json`) and is never pushed to public Git repositories.

## 3. Reporting Vulnerabilities
If you discover a security vulnerability or sensitive data leak, please open a private GitHub advisory or contact the repository owner directly.
